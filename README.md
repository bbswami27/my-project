# 💬 ChatterPatter - Chat • Share • Connect

ChatterPatter is a full-featured social chatting web application built with a modern WhatsApp-inspired interface, multi-method authentication (Mobile OTP, Google 1-Click, Email), rich messaging, voice notes, audio/video calling, status/stories, and real-time live breaking news flash tickers and channels.

---

## 🚀 Features Included

### 1. 🔐 Multi-Method Authentication
- **Mobile Number + 6-Digit OTP**: Country code selector, automated OTP generation with countdown timer and instant dev auto-fill.
- **Google / Gmail 1-Click Sign-In**: Seamless 1-tap Google login simulation.
- **Email & Password**: Custom profile creation with instant avatar selection.
- **Demo Quick Switcher**: 1-click test profiles (Alex, Priya, Rahul, Sarah) to test multi-user chat and calls instantly.

### 2. 💬 WhatsApp-Inspired Real-Time Messaging Engine
- **Chats & Groups**: Direct 1-on-1 chats and group conversations with online indicators and unread badges.
- **Message Bubbles**: Authentic WhatsApp speech bubble tails, delivery ticks (double grey & double blue read receipts), timestamps, and date dividers.
- **Voice Note Recorder**: Browser Web Audio API microphone recording with visualizer and audio playback scrubber.
- **Reactions & Quotes**: Quick emoji reactions (❤️, 👍, 😂, 😮, 😢) and message quoting/replies.
- **Media Sharing**: Image attachments, photos, documents, and emoji picker.
- **AI & Simulated Contact Responses**: Instant realistic interactive replies with typing indicators.

### 3. 🚨 Live Breaking News Flash & Channels
- **Top News Ticker (Flash Bar)**: Animated marquee header with breaking alerts that rotates every few seconds.
- **Channels & News Tab**: Categorized news feeds (Breaking, Tech, India, Business, Sports, Entertainment).
- **1-Click Share to Chat**: Forward any news article directly into any chat or group.

### 4. 📞 Audio & Video Calling UI
- Fullscreen WhatsApp call interface.
- Synthesized calling ringtones via Web Audio API.
- Video calling with local web camera stream and remote feed viewport.
- Microphone mute, camera toggle, call duration counter, and call history logs (incoming, outgoing, missed).

### 5. ⭕ Status & Stories (Updates)
- 24-Hour status timeline with colored ring indicators.
- Create color-graded text or photo status updates.
- Fullscreen story viewer with segmented progress bars, pause on hold, tap navigation, and direct reply to story.

### 6. 🎨 Branding & Customization
- High-fidelity **ChatterPatter** vector logo with smiling dual chat bubbles and paper plane.
- Dark Theme (`#111b21`) & Clean Light Mode toggle with persistence.
- Fully responsive layout across Mobile, Tablet, and Desktop.

## 📦 How to Run

1. Open terminal inside the project directory:
   ```bash
   cd C:\Users\Administrator\.gemini\antigravity\scratch\chatterpatter-app
   ```
2. Start the server:
   ```bash
   node server.js
   ```
3. Open your browser at:
   `http://localhost:3000`
